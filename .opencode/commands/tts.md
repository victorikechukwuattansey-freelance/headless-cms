---
description: Generate text-to-speech audio from text using Windows Speech Synthesis.
---

Generate a TTS audio file. Usage:

```powershell
& "C:\Users\1040 G8\Documents\jarvis-demo\scripts\tts.ps1" -Text "text to speak" -OutFile "output.wav" [-Voice "Microsoft Zira Desktop"]
```

Voices available: Microsoft Zira Desktop (en-US, default), Microsoft Hazel Desktop (en-GB). Inform the user of the output path after generation.
