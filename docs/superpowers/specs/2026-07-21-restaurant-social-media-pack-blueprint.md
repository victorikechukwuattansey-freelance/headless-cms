# Restaurant Social Media Kit — Product Blueprint

## Purpose

A 40-template Canva pack for restaurants, cafés, bakeries, and bars. Buyers can edit every template in Canva's free plan and post immediately. No design skills required.

## Target Customer

Restaurant/café/bakery owner or manager who knows Instagram content is essential but has zero time or design ability.

## Design Specification

### Color Palette

| Role | Hex | Usage |
|------|-----|-------|
| Charcoal | `#1a1a1a` | Headings, body text |
| Cream | `#faf6f0` | Backgrounds |
| Terracotta | `#c8553d` | CTAs, accents, highlights |
| Olive | `#6b8f5e` | Secondary accents, badges |
| Gold | `#e8b84b` | Price tags, star ratings, emphasis |

### Typography

| Role | Font | Fallback |
|------|------|----------|
| Headings | Playfair Display (Bold) | Georgia, serif |
| Body | Inter (Regular) | -apple-system, sans-serif |
| Price/Labels | Inter (Semi-Bold) | -apple-system, sans-serif |

Both fonts are free for commercial use on Canva.

### Layout Grid

- **Square:** 1080×1080 px — 40px padding, centered content zone
- **Story:** 1080×1920 px — 48px padding, bottom-third CTA zone
- **Carousel slide:** 1080×1350 px — 36px padding, swipe-indicator arrow (light)

### Component Library

Each template uses these reusable components:

1. **Header bar** — 1080×80px strip at top. Solid charcoal or cream bg. Resto name in Playfair.
2. **Photo frame** — Rounded 16px corners, 4px cream border, subtle drop shadow.
3. **Badge** — Pill shape, 40px height. Terracotta or Olive bg. White text, 12px Inter Semi-Bold.
4. **CTA button** — 240×52px. Terracotta fill, white text, 14px Inter Semi-Bold. 8px border radius.
5. **Price tag** — Gold badge with dollar amount, Playfair Bold 24px.
6. **Quote block** — Italic Playfair, 18px, centered, with decorative quotation mark glyph.
7. **Divider** — 2px terracotta line, 60% width, centered.

## Owner Instructions (to build in Canva)

1. Create a new Canva project at 1080×1080px
2. Set up brand kit with the 5 colors listed above
3. Save Playfair Display + Inter as preferred fonts
4. Build each template per the layout spec — use locked position for non-editable elements (brand colors, logo area) and unlocked for editable text/photo placeholders
5. Label files clearly per the folder structure above
6. For each template, set photo placeholders to "Replace this image" in Canva
7. Create a single PDF instruction page (1080×1920) with the template share link
8. Test: open the template link in an incognito browser without a Canva account — buyer should be able to edit with free tier
9. Generate preview mockups: phone mockup, laptop mockup, Instagram feed grid preview (3x3)
