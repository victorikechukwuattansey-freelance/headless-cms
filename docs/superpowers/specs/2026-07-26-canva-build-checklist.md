# Canva Build Checklist — Restaurant Social Media Kit

## Setup (30 min)

### 1. Create Brand Kit
1. Open Canva → click your avatar → **Brand Kit**
2. Add these 5 colors:
   - Charcoal `#1a1a1a` — Headings, body text
   - Cream `#faf6f0` — Backgrounds
   - Terracotta `#c8553d` — CTAs, accents, highlights
   - Olive `#6b8f5e` — Secondary accents, badges
   - Gold `#e8b84b` — Price tags, star ratings, emphasis
3. Add these 2 fonts:
   - **Playfair Display** (Bold) — Headings
   - **Inter** (Regular, Semi-Bold) — Body text, labels

### 2. Create Canva Folders
In Canva Projects, create 6 folders:
```
01 - Menu & Dishes
02 - Promotions & Offers
03 - Events & Seasonal
04 - Behind the Scenes
05 - Testimonials & Info
06 - Stories
```

### 3. Component Reference
Build these reusable elements once, copy-paste between templates:

| Component | Size | Colors | Font |
|-----------|------|--------|------|
| Header bar | 1080×80px | Charcoal bg or Cream bg | Playfair Bold, 20px, white/charcoal |
| Badge (pill) | ~200×40px | Terracotta or Olive bg | Inter Semi-Bold, 12px, white |
| CTA button | 240×52px | Terracotta fill, 8px radius | Inter Semi-Bold, 14px, white |
| Price tag | ~120×40px | Gold fill | Playfair Bold, 24px, charcoal |
| Quote block | centered, max 600px wide | — | Playfair Italic, 18px, charcoal |
| Divider line | 60% width, 2px height | Terracotta | — |

## Lock/Unlock Strategy

For each template, lock elements that shouldn't move:

| Lock | Unlock (buyer edits) |
|------|---------------------|
| Background rectangles | Photo placeholders |
| Badge positions/sizes | All text content |
| CTA button positions | Color fills (buyer can change) |
| Divider lines | Icon positions |
| Circle frame positions | |

In Canva: select element → click **Position** → toggle **Lock**.
