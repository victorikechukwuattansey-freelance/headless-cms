# NovaTech Solutions — Brand Guidelines

## Brand Overview

NovaTech Solutions is a modern technology startup providing enterprise-grade software. The identity communicates innovation, reliability, and clarity through a clean, minimal visual system.

---

## Logo System

### Primary Horizontal
Full lockup: cube icon mark + "NovaTech" wordmark + "Solutions" descriptor. Use on all standard communications.

### Stacked
Icon centered above wordmark. Use on square formats, social avatars, and space-constrained layouts.

### Icon Mark
The layered cube mark alone (blue outer, cyan inner). Use as favicon, app icon, and watermark. Never recolor or rotate.

### Minimum Sizes
- Primary: 80px wide (digital), 1 in (print)
- Icon: 24px (digital)

---

## Color Palette

| Swatch | Hex | Usage |
|---|---|---|
| Blue | #2563EB | Primary brand color, buttons, links |
| Cyan | #06B6D4 | Secondary accent, highlights, illustrations |
| Navy | #0F172A | Primary text, dark mode backgrounds |
| Slate | #64748B | Secondary text, captions, borders |
| White | #FFFFFF | Backgrounds, cards |
| Surface | #F8FAFC | Subtle backgrounds, sections |

Blue is the primary color. Cyan is an accent — use sparingly for emphasis. Navy provides strong contrast for text.

---

## Typography

### Display & Body: Inter

Use Inter across all applications — a single typeface family for consistency.

| Style | Weight | Size | Letter-Spacing |
|---|---|---|---|
| Logo | 700 | 20–44px | -0.5px |
| Display H1 | 700 | 52–80px | -2px |
| Display H2 | 600 | 32–40px | -0.5px |
| Heading | 600 | 18–24px | normal |
| Body | 400 | 14–18px | normal |
| Caption | 500 | 10–12px | +0.02–0.03em |

---

## Iconography

Use simple, geometric, outlined or filled icons with rounded corners. The cube motif can be echoed in custom icons. Stick to a single icon set — avoid mixing styles.

---

## Brand Voice

- Clear and direct
- Confident but approachable
- Technical without jargon
- Professional without being stiff

---

## Usage Rules

- Maintain generous whitespace — the brand breathes through clean layouts
- Use the blue/cyan gradient or blue as call-to-action color
- Photography should feel human — team photos, workspace candids, real product shots
- Avoid heavy textures or decorative flourishes — the design should feel engineered
