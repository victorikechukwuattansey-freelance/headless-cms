# White-Label Capabilities

## Overview

LCOS provides comprehensive white-label capabilities for Enterprise customers who want to offer the platform under their own brand. White-label spans the entire user-facing surface: domain, UI, emails, reports, and API.

---

## 1. Custom Domain

### Configuration

```
Tenant's domain:  app.luxuryboutique.com
LCOS infra:       *.lcos.app (internal)
```

### Setup Flow

1. Tenant provides custom domain (e.g., `app.luxuryboutique.com`)
2. Tenant adds CNAME record pointing to `lb.lcos.app`
3. LCOS validates DNS via TXT record
4. SSL certificate auto-provisioned via Let's Encrypt (ACMEv2)
5. Tenant's app served at `app.luxuryboutique.com`

### Domain Configuration API

```typescript
// POST /api/v1/admin/white-label/domain
{
  "domain": "app.luxuryboutique.com",
  "redirect_www": true,
  "ssl_provider": "lets_encrypt"  // or "custom" (tenant provides cert)
}

// Response
{
  "status": "pending_verification",
  "verification_method": "TXT_RECORD",
  "verification_value": "lcos-verify=abc123def456",
  "cname_target": "lb.lcos.app"
}
```

### SSL Certificate Management

| Provider | Auto-renewal | Custom Cert Upload |
|---|---|---|
| Let's Encrypt | ✅ (30 days before expiry) | ❌ |
| Custom (EV, OV) | ❌ (tenant responsible) | ✅ PEM format |

## 3. Remove "Powered by LCOS" Branding

### Branding Locations

| Location | Default | White-Label |
|---|---|---|
| Sidebar footer | "Powered by LCOS v1.2" | Hidden |
| Login page | "Powered by LCOS" footer | Hidden |
| Email footers | "Sent via LCOS" | Custom text |
| Report headers | LCOS logo | Tenant logo |
| Report footers | "Generated by LCOS" | Custom text |
| CSV/PDF exports | "LCOS Export" | Tenant brand |
| API responses | `x-powered-by: LCOS` | Removed |
| Dashboard title | "LCOS Dashboard" | Custom title |

### Implementation

```typescript
// White-label branding service
class BrandingService {
  isWhiteLabel(tenant: Tenant): boolean {
    return tenant.tier === 'enterprise' && tenant.whiteLabel.enabled;
  }

  getBranding(tenant: Tenant): AppBranding {
    if (!this.isWhiteLabel(tenant)) {
      return DEFAULT_BRANDING; // "Powered by LCOS"
    }
    return {
      appName: tenant.whiteLabel.appName || 'Dashboard',
      hidePoweredBy: true,
      footerText: tenant.whiteLabel.footerText || '',
      showLcosBadge: false,
    };
  }
}
```

## 6. Partner Onboarding Flow

### Multi-Tenant Partner Model

```
┌───────────────────────────────────────────────┐
│                  Partner (Reseller)             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐     │
│  │ Tenant A │  │ Tenant B │  │ Tenant C │     │
│  │ (Client) │  │ (Client) │  │ (Client) │     │
│  └──────────┘  └──────────┘  └──────────┘     │
│  All tenants share partner's white-label theme │
└───────────────────────────────────────────────┘
```

### Partner Dashboard

Partners get a management dashboard to:

- Create and manage client tenants
- Apply white-label theme to all sub-tenants (or per-tenant)
- View client subscription status and usage
- Handle billing (if reseller-managed)
- Access L2 support tickets

### Onboarding Steps

```
1. Contract signed
2. Partner account created (Enterprise reseller tier)
3. White-label theme configured
4. Custom domain set up
5. First client tenant created as sub-account
6. Theme auto-applied to sub-account
7. Client receives branded welcome email
8. Client logs in at custom domain
```

## 10. Technical Implementation Notes

### Theme Delivery

- Themes stored as JSON in database
- Compiled to CSS at login and cached (Redis, 1-hour TTL)
- Theme changes propagate within 5 minutes
- Custom CSS sanitized (no `javascript:` URLs, no `position: fixed` abuse)

### Domain Routing

- Wildcard DNS `*.lcos.app` → load balancer
- Custom domain CNAME → `lb.lcos.app`
- Application reads `Host` header → maps to tenant
- SSL via Let's Encrypt with automated renewal
