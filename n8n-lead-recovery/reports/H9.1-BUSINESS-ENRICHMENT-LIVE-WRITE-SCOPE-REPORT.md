## 1. Scope model

The runner operates in one of two write scopes, selected with
`--scope=<test|production>` (default `test`):

| Scope | `--execute` behaviour | Namespace guard | Env requirement |
| ----- | --------------------- | --------------- | --------------- |
| `test` (default) | Only `TEST-ENRICH-LIVE-<tag>-` lead_ids are written | Enforced (stage `FAIL` under an adversarial namespace) | `BIZ_ENRICH_ALLOW_PRODUCTION` NOT consulted |
| `production` | Every matched lead in scope is written | Not applied | `BIZ_ENRICH_ALLOW_PRODUCTION=1` REQUIRED — otherwise stage `REFUSED`, exit 1 |

There is deliberately **no `--allow-production-writes`**. Production requires two
independent acknowledgments: the `--scope=production` flag **and**
`BIZ_ENRICH_ALLOW_PRODUCTION=1` in the environment.

### The REFUSED guard

`runBusinessEnrichment` computes `requestedScope` and `productionConfirmed` on
entry and, when `--execute --scope=production` is requested without the env var,
returns **before any client construction, sheet read, or write**:

- `outcomes.stages.write = 'REFUSED'`
- failure message: `refusing production write: set BIZ_ENRICH_ALLOW_PRODUCTION=1 to confirm`
- report is still written; `would_write: 0`, `wrote: 0`, `changedCells: 0`
- overall status `FAIL` → exit 1 (REFUSED is treated as a hard failure in `overallStatusOf`)

### DRY_RUN interaction

`--scope` is parsed and reported in DRY_RUN mode but never acts: a dry run
always produces stage `DRY_RUN`, `effective_scope` reports `dry_run`, and the
production env var is never required. This keeps dry runs safe and credential-free.

## 2. Write-stage labels

| Label | Meaning |
| ----- | ------- |
| `DRY_RUN` | No `--execute`; would-write cells reported, nothing written (unchanged) |
| `PASS` | A `values.update` PUT materialized `wrote > 0` cells |
| `NO_ELIGIBLE` | `--execute` ran but no lead in scope changed — nothing to write: `execBlock.values.length === 0` (empty scope) **or** `execChanged === 0` (test scope: no `TEST-ENRICH-LIVE` lead matched/stamped; production scope: nothing matched). Formerly reported as `DRY_RUN`; now an explicit EXECUTE-stage outcome. |
| `FAIL` | Sheet write error, or (test scope only) a non-`TEST-ENRICH-LIVE` namespace |
| `REFUSED` | (H.9.1) Production requested but unconfirmed |
